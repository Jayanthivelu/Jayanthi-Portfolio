# Jayanthi V - Personal Portfolio

![Portfolio Preview](assets/hero-photo.jpg)

A modern, highly interactive, and responsive personal portfolio built to showcase my expertise in **UI/UX Design, Frontend Development, and Digital Solutions**. 

The website features custom 3D scroll animations, a glowing dark-mode aesthetic, and seamless cross-platform responsiveness.

## ✨ Features

- **Interactive 3D Scroll Animations**: Custom jump and flip effects powered by GSAP.
- **Dynamic Typewriter Effect**: Auto-cycling roles in the hero section.
- **Glowing UI/UX Aesthetics**: Custom glassmorphism, glowing borders, and particle effects.
- **Fully Responsive**: Flawless layout scaling across desktop, tablet, and mobile.
- **In-Browser PDF Download**: Seamless, tab-free CV downloading via encoded Base64 bypass.
- **Functional Contact Form**: Ready to be hooked up to EmailJS or any backend service.

## 🛠️ Technologies Used

- **HTML5 & CSS3**: Semantic structure and advanced styling (Flexbox, CSS Grid, Custom Variables, Animations).
- **Vanilla JavaScript**: Core logic, DOM manipulation, and Base64 parsing.
- **GSAP (GreenSock)**: Professional-grade scroll animations and timeline sequencing (`ScrollTrigger`, `matchMedia`).
- **ScrollReveal.js**: Smooth reveal-on-scroll animations for text and cards.

## 🚀 How to Run Locally

You don't need any complex build tools to run this portfolio. Just open the HTML file!

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Jayanthivelu/jayanthi-portfolio.git
   ```
2. **Navigate to the folder:**
   ```bash
   cd jayanthi-portfolio
   ```
3. **Open `index.html` in your browser:**
   Simply double-click the `index.html` file or use a local server like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code for the best experience.
